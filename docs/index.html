axios-auth-kit

无感刷新 + 请求去重 + 前端加解密。安装：npm i axios-auth-kit

① AES 加解密（Web Crypto 实现）

② 无感刷新 + 请求去重 核心逻辑

// 无感刷新：响应 401 时自动刷新 token 并重放原请求，且并发去重（只刷一次）
setupRefreshAuth(axios, {
  isRefreshRequest: (config) => config.url === '/api/refresh',
  refreshToken: async () => {
    const { data } = await axios.post('/api/refresh')
    return data.accessToken
  },
})

// 请求去重：相同请求并发时只发一次，结果共享
setupRequestDedupe(axios, { getKey: (config) => config.method + ' ' + config.url })
